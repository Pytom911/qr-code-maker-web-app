## ? Features

- **100% in Your Browser** – QR codes are generated locally on your device. No uploads, no tracking, no servers.
- **High-Quality SVG & PNG** – Download as vector SVG for print or 1024px PNG for digital. Free, no watermarks.
- **Error Correction Level H** – Resilient to up to 30% damage. Scans reliably even when dirty, folded, or small.
- **Instant Preview** – Paste a URL and see your QR code update in real time.
- **Custom Colors** – Pick your own foreground and background colors with quick presets.
- **Privacy First** – Everything stays on your device. Your data never leaves your browser.
- **Mobile-Friendly** – Clean, responsive UI that works great on desktop and mobile.

## ??? Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v18+ recommended) and [npm](https://www.npmjs.com/) installed.

### Installation

1. Clone the repository

`ash
git clone https://github.com/Pytom911/qr-code-maker-web-app.git
cd qr-code-maker-web-app
`

2. Install dependencies

`ash
npm install
`

3. Start the development server

`ash
npm run dev
`

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## ?? Usage

1. Enter a URL starting with http:// or https://
2. Preview appears instantly
3. Click **Download** and choose **SVG** (vector, best for print) or **PNG** (1024px, best for web/social)
